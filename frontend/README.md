# Mana Oori Santha — website

React + Vite + Tailwind storefront, seller panel and admin panel.

```bash
npm install
npm run dev      # http://localhost:5173 (expects the API on http://localhost:5000)
npm run build    # production build in dist/
npm run lint
```

Settings live in `.env` (see `.env.example`). Setup, hosting and deployment are covered in the
[main README](../README.md).
